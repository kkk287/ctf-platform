# AI 平台与工具使用说明（AI_USAGE）

## 1. 使用的平台与模型

| 项目 | 说明 |
|---|---|
| 开发环境 | Trae IDE（Agent 模式，可读写工作区、执行终端命令） |
| 对话模型 | `DeepSeek-V4.1-Flash`（IDE 内配置的模型标识，非外部 API 调用） |
| 主要能力 | 代码生成与重构、文件读写/批量替换、终端命令执行、测试运行与失败日志分析、文档撰写 |
| 未使用 | 未调用任何第三方大模型 API、未向外部服务上传源码或数据；无联网抓取代码 |

> 说明：AI 仅作为开发辅助工具参与编码与文档起草，最终产物经过本机编译、测试与接口实测复核。

## 2. 如何给 AI 下约束（本项目采用的方式）

1. **硬性门槛先行**：在首条指令中列出"必须满足并实测验证"的交付条件（可启动、可测试、可部署、文档齐全），避免只产出示例代码。
2. **技术栈锁定**：明确 Java 17、Spring Boot 3.2.x、Maven Wrapper、JPA + Flyway、JWT + BCrypt、原生前端零 CDN，减少模型自由发挥。
3. **业务规则具体化**：给出状态机、错误码语义、积分公式、榜单排序规则、战队聚合规则，而不是"做一个排行榜"。
4. **明确不做项**：列出"不做动态靶机、不做 CTFd 插件、不做 OAuth"，防止过度设计。
5. **要求自证**：要求运行 `mvnw test`、启动应用、用脚本走完整链路并把响应写入 `docs/verification.md`，禁止只写报告。
6. **环境授权与边界**：允许安装必要工具（便携优先），要求先探测已有版本、失败记录原因并给替代方案。
7. **变更纪律**：业务方向变更时要求"删除旧领域代码，不保留两套混杂实现"。

## 4. 本项目实际使用记录

完整提示词与阶段记录见 [prompts/usage-log.md](../prompts/usage-log.md)，模板见 [prompts/templates.md](../prompts/templates.md)。

| 阶段 | AI 参与内容 | 人工/实测复核 |
|---|---|---|
| 工程骨架 | pom、Maven Wrapper、application*.yml、Flyway 脚本 | `mvnw compile` 通过；H2/MySQL/PG profile 检查 |
| 领域与接口 | 实体、Repository、Service、Controller、DTO、统一响应与异常 | 逐接口梳理权限与错误码；Swagger 可访问 |
| 判分核心 | 哈希、动态积分、血奖、提示扣分、限流、审计 | 单元测试 + 集成测试断言积分与错误码 |
| 前端 | 7 类页面、CSS、原生 JS、无 CDN | 页面 HTTP 200；JS 无外链；流程实测 |
| 测试 | 单元 + MockMvc 集成测试 | `mvnw test` 全绿（见 verification.md） |
| 部署 | Dockerfile、compose、CI/CD 工作流 | 本地 compose 构建/启动验证；Actions 配置静态检查 |
| 文档 | README、PLAN、DEPLOY、DEMO、本文、verification | 人工校对路径、命令与账号一致性 |

## 5. 人工复核点（评审可重点检查）

1. **安全**：仓库无明文密钥/密码配置；`.env` 被忽略；flag 仅哈希入库；JWT 密钥来自环境变量。
2. **权限**：`/api/admin/**` 仅 ADMIN；选手访问返回 4030；战队管理校验队长身份。
3. **业务规则**：非法状态流转、重复提交、赛事未开始/已结束、限流冷却均返回明确错误码。
4. **数据一致性**：`solves` 唯一约束（user+challenge）；判分使用悲观锁；错误提交不破坏审计。
5. **部署真实性**：Dockerfile 多阶段构建可复现；compose 健康检查与数据卷；Actions 的 Secrets 名称与文档一致。
6. **测试真实性**：`docs/verification.md` 中的命令可复现；测试数量与报告一致。

## 6. 局限说明

- AI 生成的代码可能存在"看起来合理但边界未覆盖"的问题；本项目通过 10 个自动化测试与手工链路验证降低风险，但未做压力测试与渗透测试。
- 未在真实公网服务器上执行 GitHub Actions 的 SSH 部署（缺少用户服务器与密钥）；该部分为配置与脚本层面完成，需用户在服务器上最终核验（见 verification.md 的"待服务器核验"清单）。
- 未验证 MySQL / PostgreSQL 实库连接（本机无对应服务）；SQL 采用可移植写法，profile 已提供，建议上线前用目标库跑一次 Flyway。
- 前端仅做桌面端适配（≥1280px），未做移动端专项适配。
- 本说明如实记录了模型标识与工具范围，未使用外部 AI API 处理业务数据。
