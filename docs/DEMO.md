# 演示脚本（DEMO，5-8 分钟）

> 适用场景：评审现场核验 / 录屏演示。
> 环境：`http://<host>:8080/`（本地为 `http://localhost:8080/`）。
> 账号：`alice / Alice@123`（选手，0x00sec 队长）、`admin / Admin@123`（管理员）、`bob / Bob@123`（0x00sec 成员）。
> 默认 flag 见 `README.md`，演示时可直接复制。

## 0. 开场（约 30 秒）

**操作**：打开首页 → 自动跳转登录页，展示深色界面与"演示账号"快捷填充按钮。

**讲解要点**：

- Spring Boot 3 + JWT 无状态认证，前端为随 JAR 发布的原生静态页，零外网 CDN，内网可用。
- 默认 H2 文件库 + Docker 数据卷，服务器 `docker compose up -d` 即可启动。

**预期**：登录页正常渲染，无任何外链加载错误（可在 F12 Network 观察请求均指向本站）。

## 1. 登录与浏览赛事（约 30 秒）

1. 点击 `alice / Alice@123` 快捷填充 → 登录。
2. 首页顶部出现赛事切换标签：`[赛事] 秋季夺旗赛 2026 · 进行中`、`[练习] 常驻练习区 · 进行中`。
3. 当前默认落在进行中的比赛，hero 显示截止倒计时、我的进度、我的积分、当前名次。
4. 点击 `[练习] 常驻练习区`，题目卡片变为 2 道练习题。

**讲解要点**：赛事与练习为两种 Event 类型；未开始的比赛对选手不可见，练习区长期开放；两者榜单独立统计，不串分。

## 2. 练习区解题（约 1 分 30 秒）

1. 在练习区点击题目 `栈溢出入门`（Pwn / 困难 / 250 分）。
2. 详情页展示描述、附件 `pwn-intro.txt` 下载、"提示"区（锁定状态，解锁需扣分）。
3. 在提交框输入错误 flag：`flag{not_the_real_one}` → 点击提交。
   - **预期**：红色 toast/提示"flag 错误"，返回业务码 `4004`；错误次数计入限流。
4. 输入正确 flag：`flag{r3t2w1n_4nd_r0p}` → 提交。
   - **预期**：绿色提示"提交正确，一血！"，显示 `基础分 250 + 血奖 50 - 提示 0 = 最终 300`，并展示当前总分与名次。
5. 再次提交同一 flag。
   - **预期**：提示"题目已解出，请勿重复提交"（业务码 `4009`）。
6. 返回题目列表：该卡片显示 `✓ 已解出`，hero 中"我的进度 1/2、积分 300"。

**讲解要点**：服务端只存 flag 哈希；动态积分按解出人数衰减；一/二/三血按 20%/10%/5% 奖励；错误提交也落审计但事务不回滚；重复提交返回明确业务错误码。

## 3. 赛事内解题与榜单（约 1 分 30 秒）

1. 切换回 `秋季夺旗赛 2026` → 打开 `欢迎来到 CTF`（Misc / 简单 / 100 分）。
2. 提交 `flag{welcome_to_ctf_2026}` → **预期**：得分成功（若非首个解出则无血奖，展示基础分）。
3. 点击顶部导航 **排行榜**。
   - 默认当前赛事、`个人榜`：alice 出现，总分 = 赛事内得分（练习区 300 分不会串入）。
   - 点击 `战队榜`：`0x00sec` 队出现，展示成员数、总分；规则为"成员得分求和、同题只计最高"。
   - "我的名次"卡片显示当前名次；`Top N` 下拉可切换 10/20/50/100。
   - 右侧"最近动态"实时显示解题记录与血奖标签。
4. 切换赛事标签到 `常驻练习区` → 个人榜显示练习区独立的 300 分与名次。

**验证要点**：赛事榜与练习区榜互不影响；同分按最后得分时间升序。

## 4. 我的战绩与战队（约 45 秒）

1. 顶部头像 → **我的战绩**。
2. 展示：总分、解题数、名次、解题记录表、账号信息、战队信息（`0x00sec`，可复制邀请码）。
3. 队长可移除成员；普通成员可退出战队；无战队用户可创建或用邀请码加入。

**讲解要点**：战队归属影响战队榜聚合；队长权限在服务端校验，非队长调用移除接口返回 `4030`。

## 5. 管理后台（约 2 分钟）

1. 退出 → 使用 `admin / Admin@123` 登录（或另开无痕窗口）。
2. 顶部出现 **管理后台** 入口 → 进入。
3. **建练习赛**：赛事标签 → 新建 → 类型选 `PRACTICE`，名称如"评审演示练习区" → 保存。
4. **建题目**：题目标签 → 新建 → 选择刚建的练习区，填名称"评审演示题"、分类 Misc、难度简单、初始分 100、flag `flag{demo_created}` → 保存。
   - 可上传附件（≤20MB），上传后列表显示附件名；可添加 hint（如"看看源码注释"，代价 20 分）。
5. **公告**：新建公告"欢迎参加评审演示"，选手首页可见。
6. **切换回 alice**：刷新首页 → 出现新练习区与新题目 → 提交 `flag{demo_created}` → 排行榜出现得分。
7. **提交审计**：管理后台 → 提交审计 → 可看到刚才的错误/正确提交，含 IP、User-Agent、时间、结果（错误提交仅展示哈希前缀）。
8. **异常告警**：同一题目 + 同一 IP 出现 ≥2 个账号正确提交时，异常标签会出现告警行（演示可用两个账号在同一浏览器依次提交同一题）。
9. **用户管理**：搜索 `bob` → 封禁 → bob 登录返回 `4033`；解封后恢复。

**讲解要点**：管理端接口全部 `@PreAuthorize("hasRole('ADMIN')")`，选手访问返回 `4030`；封禁即时生效（每次请求重新加载用户状态）。

## 6. 收尾（约 30 秒）

- 展示 Swagger：`/swagger-ui.html`（Authorize 填 token 可调试）。
- 展示健康检查：`/actuator/health` 返回 `{"status":"UP"}`。
- 说明部署：仓库 push → Actions 构建测试 → tag 触发 GHCR 推送 → 服务器 `docker compose pull && up -d`，数据卷保留。
